# Classroom Management System

A database-oriented classroom management system with a multi-role frontend for **Administrators, Faculty, and Students**.

## Project Overview

This project demonstrates the design of a classroom management system interface intended to work with an underlying database. The frontend includes separate views and account-management pages for different user roles, including administrators, faculty members, and students.

The project focuses on organizing common academic management workflows through a role-based interface.

## User Roles

### Administrator
The administrator interface is designed for managing the broader system and user information.

### Faculty
Faculty pages provide role-specific profile and account functionality for instructors.

### Student
Student pages provide profile and account functionality for enrolled students.

## Main Frontend Pages

The project includes pages such as:

- Home / landing page
- Search page
- Student listing
- Faculty listing
- Student profile
- Faculty profile
- Administrator profile
- Student password change
- Faculty password change
- Administrator password change
